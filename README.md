# To-Do

Тестове завдання для вимірювання розуміння технологій React, Mui та Redux

[Переглянути додаток (Деплой)](https://starlit-pony-d289d6.netlify.app/)

## Реалізовані функції:

- Додавання, редагування, видалення завдання
- Сортування
- Фільтрація
- Валідація тексту
- Анімація переміщення завдань

## Інструкція для клонування репозиторію та запуску проекту на локальному сервері:

1. Склонуйте репозиторій на свій комп'ютер:

   ```bash
   https://github.com/rick-jackson/to-do_test.git
   ```

2. Перейдіть в папку проекту:
   ```bash
   cd to-do_test
   ```
3. Встановіть необхідні залежності:
   ```bash
   npm install
   ```
4. Запустіть проект на локальному сервері:

   ```bash
   npm run dev

   ```
